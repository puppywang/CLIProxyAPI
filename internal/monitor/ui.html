Stall timeout: 0 disables. When >0, any request with no response activity for that many seconds is cancelled (catches dead/silent streams). Slow window + min bytes form a throughput floor: once a stream is producing bytes, if fewer than the min bytes arrive in any window of that many seconds, it is cancelled as a slow "trickle" stream. Both slow knobs must be >0 to enable; either at 0 disables the slow watchdog.
